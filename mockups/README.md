# Mockup blanks

Four pictures used by the Mockup view (`js/editor/mockup.js`): a white hoodie and a white T-shirt, front and
back, 2000 x 2000 px, greyscale with a transparent background. The editor tints them to any colour.

| File | Made from |
| --- | --- |
| `hoodie-front.webp`, `hoodie-back.webp` | "White Front Blank" / "White Back Blank", REENO Blank Hoodie Mockup Pack |
| `tee-front.webp`, `tee-back.webp` | "White Front Blank" / "White Back Blank", REENO Blank Mockup Pack |

@reenostus). The pack's README does not say whether the blanks may be redistributed, and putting them in a

of `js/editor/mockup.js`.
